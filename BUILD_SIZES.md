## 2. Technical Evidence: Why APK Size Appears to "Shrink"

There has been **zero removal or loss** of application code, models, fonts, or assets. The size variance across builds is mathematically and structurally explained by three architectural factors:

### Factor A: Universal (Fat) APK vs. ABI Split APKs
A standard Android APK generated by `flutter build apk` is a **Universal "Fat" APK**. It bundles every compiled native library for three distinct CPU architectures:
1. `lib/arm64-v8a/`: 29.06 MB uncompressed (Modern 64-bit ARM phones)
2. `lib/armeabi-v7a/`: 24.83 MB uncompressed (Older 32-bit ARM phones)
3. `lib/x86_64/`: 32.35 MB uncompressed (Desktop/Emulators)
**Total native libraries in Universal APK: 86.24 MB uncompressed.**

When built with `--split-per-abi`, Gradle packages **only the specific CPU architecture needed for each target platform**. For the `arm64-v8a` APK:
- The 24.83 MB of `armeabi-v7a` binaries are omitted.
- The 32.35 MB of `x86_64` binaries are omitted.
- **Net size reduction: ~53 MB**. The APK shrinks from 89 MB to 35.68 MB purely by omitting redundant CPU machine binaries that your phone cannot execute anyway.

### Factor B: Debug vs. Release Compilation (JIT vs. AOT)
- In **Debug** mode (`app-dev-debug.apk` = 228.7 MB), the APK includes:
  - The Dart JIT (Just-In-Time) compiler and runtime engine.
  - Dart VM debugging tools, observatory service, and hot reload sockets.
  - Complete source maps and uncompressed class definitions.
- In **Release** mode (`app-prod-release.apk` = 89.0 MB), Dart Ahead-Of-Time (AOT) compiles Dart code directly to stripped ELF machine binaries (`libapp.so`), eliminating all JIT/debugging overhead.

### Factor C: Material Icons Tree-Shaking
- Default Flutter release builds analyze code and strip unused glyphs from `MaterialIcons-Regular.otf` (reducing it from 1,645,184 bytes down to ~23,364 bytes).
- In this build, we passed `--no-tree-shake-icons` so the complete, intact `MaterialIcons-Regular.otf` font (1,645,184 bytes) is bundled without any stripping.

## 5. Review of R8, ProGuard, and `shrinkResources` Rules

File: `android/app/proguard-rules.pro` and `android/app/build.gradle`

### Build Configuration:
```gradle
buildTypes {
    release {
        signingConfig (keystorePropertiesFile.exists() ? signingConfigs.release : signingConfigs.debug)
        minifyEnabled true
        shrinkResources true
        proguardFiles getDefaultProguardFile("proguard-android-optimize.txt"), "proguard-rules.pro"
    }
}
```

### ProGuard / R8 Rules Analysis:
1. `-keep class io.flutter.app.** { *; }` & `io.flutter.plugin.**`:
   - **Preserves:** Entire Flutter engine binding, lifecycle handlers, and platform channels.
   - **Prevents:** MethodChannel invocation failures or blank screens on launch.
2. `-keep class org.tensorflow.lite.** { *; }` & `com.tflite.**`:
   - **Preserves:** TensorFlow Lite JNI bindings, native tensor allocations, GPU delegate initializers.
   - **Prevents:** `UnsatisfiedLinkError` or `ClassNotFoundException` during disease scanning.
3. `-keep class org.sqlite.** { *; }`, `io.simform.drift.**`, `com.tekartik.sqflite.**`:
   - **Preserves:** SQLite native library loaders and Drift schema migrations.
   - **Prevents:** Database crashes during offline caching of Mandi prices or orders.
4. `-keep class com.razorpay.** { *; }` & `@android.webkit.JavascriptInterface`:
   - **Preserves:** Razorpay checkout WebView bridge and payment callback handlers.
   - **Prevents:** Payment gateway silent drops or crash on order checkout.
5. `-keep class com.it_nomads.fluttersecurestorage.** { *; }`:
   - **Preserves:** Android Hardware Keystore AES cipher encryption classes.
   - **Prevents:** Session token corruption on app restart.
6. `-keep class com.fluttercandies.flutter_image_compress.** { *; }`:
   - **Preserves:** Native JPEG/WebP compression libraries for camera image optimization.
7. `-keep class com.csdcorp.speech_to_text.** { *; }` & `com.tundralabs.fluttertts.**`:
   - **Preserves:** Android SpeechRecognizer and TextToSpeech native audio delegates for Krishi Sahayak voice AI.
8. `-keep class net.nfet.flutter.printing.** { *; }`:
   - **Preserves:** Android PrintManager native adapter for PDF invoice printing.

**Impact of `shrinkResources true`:**
- `shrinkResources true` operates exclusively on unreferenced Android XML drawables/layouts in `res/`.
- It does **NOT** touch Flutter assets (`assets/flutter_assets/*`), which are packaged directly into the APK assets root and loaded via Flutter's C++ asset manager.
- Zero required code or resources are stripped.
