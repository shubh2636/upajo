## 1. Trademark Registry Search (India — IP India)

- **Wordmark Search Criteria**:
  - Search Type: `Wordmark`
  - Text: `UPAJO` and phonetic variant `UPOJO`
  - Class 31: Agricultural, horticultural and forestry products, grains, fresh fruits and vegetables.
  - Class 35: Advertising, business management, commercial administration, online agricultural marketplace services.
  - Class 42: Scientific and technological services, agricultural AI software, software as a service (SaaS).
  - Class 9: Downloadable mobile applications, computer software.
- [ ] Check for exact matches in Class 31, 35, 42, 9.
- [ ] Check for phonetically similar marks (e.g., *Upaj*, *Upaja*, *Upajog*).
- [ ] Check Status: Abandoned, Registered, Objected, Opposed, or Pending.
